# TFG - Beyond the scoreline: Analysis of xG and Goal Efficiency in European Football

This repository contains the code and resources used for my Final Degree Project, focused on the analysis of the relationship between expected goals (xG) and actual goals in European football leagues.

The project applies machine learning models such as Decision Tree, Random Forest and XGBoost to study the variable diff_xG, defined as the difference between actual goals scored and expected goals.

This repository contains the code developed for the Final Degree Project by Pablo Pérez Agudo and Álvaro Gómez Doce, students at Universidad Complutense de Madrid.
